<h1>Módulos y funcionalidades del sistema</h1>
<p>El panel del <strong>administrador</strong> de EcoLact está organizado en <strong>11 secciones de navegación con 19 opciones visibles</strong>. Estas secciones agrupan las funciones para gestionar el acopio, la calidad, el personal, los pagos, la producción y la comercialización. No representan 11 aplicaciones independientes: cada rol dispone de las opciones que le corresponden.</p>

<div class="ec-bottom-strip"><span class="ec-round-icon">i</span><div><strong>Cómo interpretar estas secciones</strong><p>Las tarjetas reproducen las secciones del menú del administrador; no son once subsistemas distintos. Por ejemplo, los recorridos y la identificación QR pertenecen a Operación → Acopio, mientras que la liquidación y el pago a proveedores forman parte de Finanzas → Pagos. El menú de otros roles muestra funciones diferentes.</p></div></div>

<p class="ec-evidence"><strong>Base de esta clasificación:</strong> menú administrativo mostrado en EcoLact y rutas web del repositorio. La opción «Auditoría» aparece en la interfaz proporcionada, aunque no se localizó una ruta web explícita con ese nombre en <code>routes/web.php</code>.</p>
