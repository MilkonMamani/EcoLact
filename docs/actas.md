# 2. ACUERDOS

## 2.1 Idea elegida

Se acuerda desarrollar la aplicación **"EcoLact"**, una plataforma móvil para la gestión integral del proceso de acopio de leche.

Su propósito será digitalizar y centralizar el registro de proveedores, las entregas de leche y el control de calidad, permitiendo realizar un seguimiento de la cantidad entregada, los resultados de los análisis y el historial de cada proveedor.

La propuesta fue seleccionada debido a que responde a una necesidad real relacionada con el acopio de leche en el Distrito de Huata, donde el registro y seguimiento de las entregas, proveedores y controles de calidad pueden realizarse de manera manual o desorganizada.

Además, la idea presenta un alcance viable para el desarrollo durante el semestre, permite trabajar con una entidad principal para el CRUD, requiere autenticación de usuarios y cuenta con una capacidad nativa mediante el uso de códigos QR para identificar a los proveedores.

## 2.2 Ideas descartadas

Durante la lluvia de ideas se consideraron las siguientes alternativas:

- **AgroControl:** Menor diferenciación debido a la existencia de numerosas soluciones para gestión agrícola.
- **GanadoControl:** Mayor complejidad por la cantidad de controles especializados que requiere.
- **ObraControl:** Alcance difícil de delimitar por las múltiples variables relacionadas con trabajadores y pagos.
- **FeriaLocal:** Menor innovación debido a la gran cantidad de sistemas de ventas e inventario existentes.
