# Documentación Técnica - EcoLact

## Resumen general

**EcoLact** es un sistema orientado a la gestión del acopio de leche, permitiendo registrar productores, controlar las entregas de leche y consultar el historial de recepción.

El sistema busca facilitar el registro y seguimiento de las entregas realizadas por los productores de leche, manteniendo organizada la información necesaria para el proceso de acopio.

## Objetivo

Desarrollar un sistema que permita gestionar de manera organizada la información relacionada con los productores y las entregas de leche realizadas durante el proceso de acopio.

## Alcance inicial

El sistema contempla principalmente:

- Gestión de productores de leche.
- Registro de entregas de leche.
- Consulta del historial de entregas.
- Edición y eliminación de registros.
- Autenticación de usuarios.

## Estado del proyecto

Actualmente el proyecto se encuentra en la etapa inicial de análisis y modelado.
