# Problema de negocio

El proceso de acopio puede presentar dificultades cuando la información
se registra manualmente o se encuentra dispersa.

Los principales problemas son:

- Dificultad para controlar las entregas diarias.
- Errores en el registro de cantidades.
- Falta de trazabilidad de los productores.
- Busqueda demorosa de planilla.
- Poca visibilidad sobre la calidad de la leche.
- Dificultad para consultar información histórica.
