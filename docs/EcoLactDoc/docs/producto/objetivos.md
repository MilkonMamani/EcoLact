# Objetivos

## Objetivo general

Desarrollar una plataforma que permita gestionar de forma centralizada,
trazable y segura las operaciones de acopio de leche.

## Objetivos específicos

- Digitalizar el registro de entregas.
- Mantener actualizada la información de los proveedores.
- Controlar la calidad de la leche recibida.
- Automatizar el cálculo de pagos.
- Mejorar la consulta de información operativa.
- Aplicar control de acceso por roles.
