# Propuesta de solución

EcoLact proporciona una plataforma centralizada para administrar
el proceso de acopio de leche.

La solución permite:

- Registrar entregas de leche.
- Identificar al proveedor y al acopiador.
- Registrar análisis de calidad.
- Administrar reglas de pago.
- Calcular liquidaciones.
- Gestionar usuarios y permisos.
- Consultar información mediante dashboards y reportes.
- Seguimiento de historial de proveedores y acopiadores
