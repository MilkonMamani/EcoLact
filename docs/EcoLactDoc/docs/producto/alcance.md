# Alcance

El sistema incluye los siguientes procesos:

- Administración de acopiadores.
- Administración de proveedores.
- Gestión de zonas.
- Registro de entregas.
- Control de calidad.
- Gestión de lotes de producción.
- Liquidación de pagos.
- Configuración de parámetros del sistema.
- Control de acceso según roles.

El alcance no incluye procesos contables externos ni integraciones
bancarias automáticas, salvo que sean implementadas posteriormente.
