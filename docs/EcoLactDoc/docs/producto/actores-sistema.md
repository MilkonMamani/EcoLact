# Actores del sistema

| Actor | Responsabilidad |
|---|---|
| Administrador | Configura el sistema y administra usuarios |
| Acopiador | Registra y gestiona entregas de leche |
| Responsable de calidad | Registra análisis y resultados de calidad |
| Responsable de producción | Gestiona lotes de producción |
| Responsable de liquidación | Calcula y gestiona pagos |
| Proveedor | Persona que entrega la leche |
