# Documentación Técnica - EcoLact

## Resumen general

EcoLact es una plataforma web para gestionar el acopio de leche,
los proveedores, el control de calidad, la producción y la liquidación
de pagos.

El sistema permite registrar las entregas realizadas por los productores,
validar la calidad de la leche, administrar los lotes de producción y
calcular los pagos correspondientes.

## Tecnologías principales

| Tecnología | Uso |
|---|---|
| Laravel | Desarrollo del backend |
| PHP | Lenguaje principal |
| MySQL | Base de datos |
| Blade | Vistas de la aplicación |
| Vite | Compilación de recursos frontend |
| Pest | Pruebas automatizadas |
| Composer | Gestión de dependencias PHP |
| npm | Gestión de dependencias frontend |

## Módulos principales

- Gestión de acopio.
- Gestión de proveedores.
- Control de calidad.
- Gestión de producción.
- Liquidación de pagos.
- Administración de usuarios.
- Gestión de roles y permisos.
- Dashboard administrativo.

## Objetivo de la documentación

Esta documentación explica la visión del producto, la arquitectura,
el modelo de dominio, la instalación, el uso, las APIs, las pruebas
y el mantenimiento del sistema EcoLact.
