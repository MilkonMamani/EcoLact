# Entidades

## Entrega de leche

Representa una entrega realizada por un proveedor en un centro de acopio.

Atributos principales:

- Identificador.
- Proveedor.
- Acopiador.
- Zona.
- Cantidad entregada.
- Fecha de entrega.
- Estado.
- Resultado del análisis de calidad.

## Proveedor

Representa a la persona que suministra la leche al centro de acopio.

## Análisis de calidad

Representa la evaluación realizada a una entrega de leche.

## Lote de producción

Agrupa la leche recibida que será utilizada en un proceso de producción.
