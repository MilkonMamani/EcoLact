# Reglas de negocio

- Una entrega debe estar asociada a un proveedor.
- La cantidad entregada debe ser mayor que cero.
- Una entrega debe registrar una fecha válida.
- El proveedor debe encontrarse activo.
- Una entrega puede requerir un análisis de calidad.
- Una liquidación debe utilizar las reglas de pago vigentes.
- Solo los usuarios autorizados pueden modificar información.
