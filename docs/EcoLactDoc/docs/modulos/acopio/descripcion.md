# Módulo de acopio

## Propósito

Gestionar el registro y control de las entregas de leche realizadas
por los proveedores.

## Funcionalidades

- Registrar una entrega.
- Consultar entregas.
- Editar información permitida.
- Cambiar el estado de una entrega.
- Consultar el historial de entregas.

## Flujo principal

1. El acopiador identifica al proveedor.
2. Registra la cantidad entregada.
3. Selecciona la zona correspondiente.
4. El sistema valida los datos.
5. Se registra la entrega.
6. La entrega queda disponible para control de calidad.
